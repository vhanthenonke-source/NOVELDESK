# NOVEL DESK v0.2 — 개인용 집필실 프로토타입

다크 모드 반응형 PWA 화면 프로토타입입니다.

## 실행
파일을 HTTPS 정적 호스팅(GitHub Pages, Cloudflare Pages, Netlify 등)에 업로드한 뒤 Safari에서 주소를 엽니다. iPhone/iPad에서는 공유 메뉴 → 홈 화면에 추가로 앱처럼 실행할 수 있습니다.

## 현재 작동 기능
- 회차 추가/삭제, 제목/본문 편집 및 자동 저장
- 회차 글자 수, 일일 목표 표시
- 등장인물/세계관 노트 CRUD
- 사건/복선 타임라인 및 상태/관련 회차 입력
- 월간 집필 캘린더 및 원고량 요약
- 현재 회차 TXT 내보내기
- 전체 데이터 JSON 백업/복원

## 아직 연결되지 않은 기능
계정 로그인/클라우드 동기화, AI 교정, DOCX/PDF 내보내기는 UI/설계 단계이며 실제 서버 연결이 아닙니다. 이 프로토타입 데이터는 브라우저 localStorage에만 저장됩니다. 브라우저 데이터 삭제 전 반드시 백업하세요.

상세 설계는 DEVELOPMENT_PLAN.md를 확인하세요.
